# Voxel3


## Why is it for?
Voxel3 is a software project oriented to generating 3D models with text prompts. 

It generates a .obj file that can be used in game development, prototyping, and more. 

## How to use it:
Download the .zip file. You also need Python installed on your machine.

Then, acess the terminal on the main folder and create a virtual environment:
(Windows) python -m venv venv

After this, activate it:
(Windows) venv/Scripts/activate

Soon after this, install the dependencies on the requirements.txt file:
pip install -r "requirements.txt"

And, after everything is done, run the main file:
python main.py
